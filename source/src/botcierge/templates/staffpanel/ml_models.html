Recommendation models

The five machine-learning models that turn a customer's request into a plan: task type, robot, attachments, skill pack and hours. These run on our server when a plan is made. They are not the skill packs, which are the software that runs on the robot.

Below: how each one scored when it was trained, and whether it knows today's catalogue. To retrain: from source/ml/ run python generate_data.py then python train_models.py, then restart the server.
